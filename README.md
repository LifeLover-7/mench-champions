# منچ قهرمانان | Mench Champions

بازی منچ تک‌دستگاهی و دوزبانه (فارسی و انگلیسی) با نمای سه‌بعدی، محیط‌ها و مهره‌های متنوع. نسخه وب یک فایل HTML مستقل و آفلاین است؛ سورس بسته‌بندی اندروید نیز جداگانه در همین مخزن قرار دارد.

## اجرای نسخه وب

فایل `index.html` را در Chrome یا Edge باز کنید. بدون نصب وابستگی اجرا می‌شود. برای اجرا از طریق یک سرور محلی (اختیاری):

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید. صدا پس از نخستین تعامل کاربر فعال می‌شود. تنظیمات، پیشرفت و فعال‌سازی در حافظه محلی همان مرورگر یا برنامه ذخیره می‌شوند و پاک کردن داده‌ها ممکن است آن‌ها را حذف کند.

## ساختار پروژه

```text
index.html                         نسخه اصلی وب، شامل کد و منابع مورد نیاز بازی
android/                           پروژه Android Studio و بسته‌بندی WebView
android/app/src/main/assets/index.html  نسخه بازی برای اندروید (کپی همگام‌شده)
assets/reference/                 لوگوی اصلی و تصاویر مرجع طراحی
scripts/sync_android.py            همگام‌سازی نسخه وب با اندروید
scripts/check_project.py           کنترل اولیه سینتکس و همگام بودن فایل‌ها
AGENTS.md                          راهنمای ابزارهای کدنویسی و گفتگوهای جدید
```

تصاویر مرجع برای توسعه نگه‌داری شده‌اند و در زمان اجرای بازی فراخوانی نمی‌شوند؛ قبل از انتشار عمومی یا تجاری، حقوق انتشارشان را بررسی کنید.

فایل اصلی برای تغییر بازی **`index.html` ریشه مخزن** است. پس از هر تغییر در آن، این دستور را اجرا و هر دو فایل را commit کنید:

```bash
python3 scripts/sync_android.py
python3 scripts/check_project.py
```

اسکریپت بررسی برای کنترل سینتکس JavaScript به Node.js نیاز دارد؛ خود بازی نیازی به Node.js ندارد. اسکریپت جای تست دستی بازی را نمی‌گیرد.

## اندروید

پوشه `android` را در Android Studio باز کنید. پروژه از JDK 17، Android SDK 34، Android Gradle Plugin 8.5.2 و Gradle 8.7 استفاده می‌کند. پس از همگام‌سازی Gradle، از **Build > Build APK(s)** برای APK آزمایشی استفاده کنید. دانلود ابزار ساخت و وابستگی‌های Gradle به اینترنت نیاز دارد، اما بازی پس از نصب به اینترنت متکی نیست. خروجی release به کلید امضای متعلق به صاحب پروژه نیاز دارد. کپی HTML اندروید در این بسته با نسخه وب همگام شده، اما APK جدید با این بسته ساخته یا روی دستگاه واقعی آزمایش نشده است.

## انتشار و امنیت پرو

- ابزار تولید کد، کلید خصوصی امضای قدیمی، keystore و خروجی‌های APK داخل این مخزن نیستند؛ آن‌ها را جداگانه و امن نگه دارید و commit نکنید.
- فعال‌سازی کوتاه فعلی **برای محافظت تجاری قابل اتکا نیست**: داده لازم برای بررسی کد در کلاینت موجود است و با بررسی برنامه می‌توان کد جعل کرد. انتشار عمومی سورس این کار را آسان‌تر می‌کند. کدها همچنین قابل اشتراک‌گذاری و آفلاین غیرقابل‌لغوند.
- برای فروش واقعی از اعتبارسنجی سمت سرور/سیستم پرداخت معتبر استفاده کنید؛ صرف خصوصی کردن مخزن هم نسخه نصب‌شده را امن نمی‌کند.
- `index.html` همچنین تأییدکنندهٔ امضای عمومی کدهای قدیمی را نگه می‌دارد؛ کلید خصوصی آن نباید در مخزن بازی قرار گیرد.

## وضعیت مجوز

مجوز انتشار این مخزن هنوز مشخص نشده است. کتابخانه‌ها و فونت‌های موجود در فایل مستقل ممکن است مجوزهای جداگانه داشته باشند؛ پیش از انتشار عمومی یا تجاری، مالکیت و شرایط مجوز همه منابع را بررسی و مجوز مناسب را اضافه کنید.
